# Fetch Brag Video Plan

## Product
Fetch — an AI agent that lets users tell Fetch what they need and coordinates the work instead of making them choose which app to open.

## Branch
merge-customer-ui

## Primary hook
"Stop figuring out which app to open."

## Runtime target
20–25 seconds. This is the concise Brag-style launch cut.

## Storyboard

### 0–2s — Problem
Visual: rapid but restrained flashes of multiple service/app contexts.
On-screen:
"Too many apps."
Then:
"One simple request shouldn't require all of them."

### 2–5s — Fetch reveal
Use the actual Fetch customer UI.
On-screen:
"Meet Fetch."
Subline:
"Your AI for getting things done."

### 5–10s — The request
Use the real customer chat UI.
User types:
"Get me 2 KitKats and milk"
Fetch responds:
"Got it. I’ll find those for you."

Keep the camera focused on the real UI and cursor/input motion.

### 10–15s — Orchestration
Show the real Fetch task/agent flow and status transitions.
Emphasize:
UNDERSTANDING → COORDINATING → PROVIDER/ACTION → RESULT

Do not invent a fake autonomous "AI brain."
Use clean motion lines or subtle UI callouts around the existing Fetch workflow.

### 15–19s — User control
Show the confirmation/approval state if available in the actual UI.
Message:
"Ready for your approval"
Then a clean confirmation action.

Important: do not depict a real third-party transaction as completed unless the project actually demonstrates it. Treat any provider integration shown in the video as prototype/simulated if needed.

### 19–23s — Broader capability
Fast cuts of actual supported Fetch request patterns:
"Find the latest news about AI agents"
"Find me a good restaurant for tonight"
"Get me 2 KitKats and milk"

Message:
"One conversation. Many tasks."

### 23–25s — Punchline
Full-screen Fetch brand.
"YOU ASK."
"FETCH FIGURES OUT HOW."

## Creative direction
- Premium early-stage AI startup launch film.
- Minimal, editorial, believable.
- Use the actual Fetch UI wherever possible.
- Neutral off-white / black visual language matching the existing UI.
- Very subtle motion accents only.
- No neon AI brain, robots, holograms, generic SaaS stock footage, or exaggerated sci-fi.
- Typography should feel like the existing Space Grotesk / DM Sans design language.
- Hook must land within the first 2 seconds.
- Music: restrained, modern electronic pulse; build slightly through orchestration; clean stop on final brand line.
- Sound design: keyboard/input click, subtle UI confirmation ticks, soft transition sounds.

## Claims discipline
The video must show what the current MVP demonstrates. Do not claim that Fetch has completed a real Swiggy/Amazon/Uber transaction if the flow is only simulated or integration-ready.

## Final message
"Fetch"
"Your AI for getting things done."
"You ask. Fetch figures out how."
